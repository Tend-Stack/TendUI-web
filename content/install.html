1. Add the preview module

Use Go 1.26 or newer. Pin this preview version for reproducible builds:

mkdir my-tendui-app
cd my-tendui-app
go mod init example.com/my-tendui-app
go get github.com/Tend-Stack/TendUI/v2026@v2026.2.0-preview.2
go install github.com/a-h/templ/cmd/templ@v0.3.1100

Using another stack? Start with plain HTML and CSS.

2. Create a page

Save this as page.templ. Go structs configure components; ordinary HTML supplies the content.

package main

import "github.com/Tend-Stack/TendUI/v2026/components"

templ page() {
	@components.Layout(components.LayoutProps{
		Title:    "My TendUI app",
		Language: "en",
		Theme:    components.ThemeSystem,
	}, body())
}

templ body() {
	<main>
		<h1>Hello, TendUI.</h1>
		@components.Card(components.CardProps{}) {
			<p>This page and its stylesheet ship in one Go binary.</p>
			<details>
				<summary>What does the browser need?</summary>
				<p>Just HTML and CSS. This disclosure works without JavaScript.</p>
			</details>
		}
	</main>
}

3. Serve the page and stylesheet

Save this as main.go.

// A complete TendUI application. The generated page and CSS ship in its binary.
package main

import (
	"log"
	"net/http"
	"time"

	"github.com/Tend-Stack/TendUI/v2026"
	"github.com/a-h/templ"
)

func handler() http.Handler {
	mux := http.NewServeMux()
	mux.Handle(tendui.AssetPath, tendui.AssetHandler())
	mux.Handle("GET /{$}", templ.Handler(page()))
	return mux
}

func main() {
	server := &http.Server{
		Addr: "127.0.0.1:8080", Handler: handler(),
		ReadHeaderTimeout: 5 * time.Second,
	}
	log.Fatal(server.ListenAndServe())
}

4. Generate and run

templ generate
go run .

Open http://127.0.0.1:8080. If templ is not on your PATH, use the executable in $(go env GOPATH)/bin/templ. The generator is needed when authoring your own templ pages; the library includes its generated Go.

5. Ship one binary

go build -o my-tendui-app .

Your generated page and TendUI stylesheet are compiled into the executable using Go's native embedding. No runtime asset directory, Node.js, npm or bundled JavaScript is needed. Add application-specific storage, routing and production server configuration as required.

This is the tested quickstart in the preview source.

Versioning

Releases use YEAR.RELEASE.FIX. This prerelease is v2026.2.0-preview.2; API changes remain possible before stable release. The /v2026 module suffix follows Go's major-version rules. Historical pre-rename tags are not TendUI installation targets.
