A small foundation, with room to grow.

GothUI gives ordinary HTML a consistent visual language and wraps it in typed Go components. Your application owns the routes, the data, and the behavior. The CSS travels inside your binary.

Start with a working page.

Follow the installation guide, then choose a component from the catalog. Every component has a compiled preview and a downloadable templ recipe.

What you get

  • 36 composable components for layouts, forms, navigation, feedback, and data.
  • Light, dark, and system color modes with configurable density and typography.
  • Embedded semantic CSS and 24 inline SVG icons.
  • Native interactions, optional bounded CSS motion, and explicit HTMX attributes.

What your application supplies

GothUI does not own authentication, routing, persistence, sessions, or request protection. It does not ship a JavaScript runtime. If you choose HTMX, you supply that runtime and the response behavior.

Three packages

Production package responsibilities
Import suffixResponsibility
gothui (module root)Embedded stylesheet and asset handler.
/componentsTyped templ components and appearance settings.
/renderFull-page and fragment HTTP responses.

The asset and render helpers use the Go standard library. Components depend on templ. Generated Go is included, so consuming the library does not require its generator; authoring your own templ pages does.

Explore by doing

Use the playground to test states and appearance, the application examples to see complete flows, and the component reference to take a recipe into your own app.
