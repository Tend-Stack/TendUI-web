Beautiful interfaces. No build pipeline.

Pure CSS. Semantic HTML. No Node.js, no npm, no bundled JavaScript. First-class Go and templ support.

Use the standalone stylesheet with any HTML-producing stack. In Go, the asset package uses //go:embed to bundle it in your binary, and typed templ components make composition convenient. Your application owns routing, data, and behavior. HTMX is optional and supplied by your application.

Start with a working page.

Choose the Go/templ quickstart or plain HTML/CSS guide, then choose a component from the catalog. Every component has a compiled preview and a downloadable templ recipe.

What you get

  • 37 composable components for layouts, forms, navigation, feedback, and data.
  • Light, dark, and system color modes with configurable density and typography.
  • Embedded semantic CSS and 24 inline SVG icons.
  • Native interactions, optional bounded CSS motion, and explicit HTMX attributes.

What your application supplies

TendUI does not own authentication, routing, persistence, sessions, or request protection. It does not ship a JavaScript runtime. If you choose HTMX, you supply that runtime and the response behavior.

Three packages

Production package responsibilities
Import suffixResponsibility
tendui (module root)Embedded stylesheet and asset handler.
/componentsTyped templ components and appearance settings.
/renderFull-page and fragment HTTP responses.

The asset and render helpers use the Go standard library. Components depend on templ. Generated Go is included, so consuming the library does not require its generator; authoring your own templ pages does.
